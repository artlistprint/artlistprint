Политика конфиденциальности

Сайт artlistprint.ru уважает конфиденциальность своих пользователей.

1. Сбор информации

Наш сайт не требует регистрации, не запрашивает персональные данные (имена, адреса электронной почты, телефоны) и предоставляется полностью бесплатно.

2. Файлы Cookie и аналитика

Сайт может использовать стандартные файлы cookie и счетчики веб-аналитики (например, Яндекс.Метрика) для сбора обезличенной информации о посещаемости с целью улучшения работы сервиса.

3. Внешние ссылки

Сайт хостится на платформе GitHub Pages. GitHub может собирать технические логи (IP-адреса) в целях обеспечения безопасности и стабильности работы сервиса.

4. Контакты

По всем вопросам работы сайта вы можете связаться с администрацией сайта по электронной почте: info@artlistprint.ru
